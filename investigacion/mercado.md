# Mercado y fuentes
Comparación conceptual para este prototipo, no evaluación de versiones o precios: hojas de cálculo permiten análisis manual; dashboards BI ofrecen métricas y filtros; asistentes conversacionales permiten preguntar en lenguaje natural. Nuestro alcance combina panel y consultas con trazas MCP. No se afirma ventaja comercial probada: no se han realizado entrevistas ni un benchmark de competidores.

Fuentes primarias:
- Dataset y contexto real: https://archive.ics.uci.edu/dataset/352/online+retail
- Requisitos docentes: https://hackathon-inesdi-bi-agentico-publico.diegogaspar.chatgpt.site
- SDK MCP usado y adaptado a las herramientas BI: https://github.com/modelcontextprotocol/python-sdk
- FastAPI usado para API local: https://github.com/fastapi/fastapi
- Modelos realmente disponibles: consulta autenticada a la API de Groq, comprobada durante la implementación; sin guardar credenciales.

Decisión crítica: Superstore es una muestra ficticia; se conserva como historial pero no se utiliza como prueba de datos empresariales reales.
