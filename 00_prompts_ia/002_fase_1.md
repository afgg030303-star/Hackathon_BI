**Visión Final del Proyecto: "Auditor Agéntico de Rentabilidad"**
Vamos a construir un sistema de Business Intelligence autónomo. El usuario final preguntará en un frontend: *"¿Por qué perdemos dinero en el Sur?"*.
El flujo que debes construir será:
1. El **Agente (LLM)** recibe la pregunta vía API (FastAPI).
2. El Agente decide usar una herramienta de un **Servidor MCP**.
3. El Servidor MCP se conecta a **PostgreSQL (Supabase)**, ejecuta una query analítica sobre el dataset real de ventas y devuelve los datos.
4. El Agente analiza los datos devueltos (ej. *"El margen es negativo por un 30% de descuento promedio en la categoría Mobiliario"*) y devuelve una recomendación de negocio accionable al frontend.
